### 不用docker容器，如何运行前后端代码

很难想象我居然没记录不用docker容器，如何把程序跑起来，尤其是如何用nginx的情况！难道是记录哪里给忘了？

1. 首先起 redis-server
2. .env 设置环境变量 NGINX 来决定使用nginx还是 express来提供静态文件。注意，目前代码express提供的静态文件不是前端代码，而是简单的websocket调试页面；要用nginx把这个环境变量设置为true
3. websocket服务器（nodejs）起在3000端口便于nginx调试
4. nginx配置文件：在我的机器做了 `nginx -t` 在系统缺省的nginx配置路径 /usr/local/etc/nginx/nginx.conf 里加了 软连接到项目中设置nginx配置文件  `websocket.conf -> /Users/qiulang/Project/call_center/ws_redis/nginx/websocket.conf`
5. 前端代码 `npm run build` ; 如果想通过 http://localhost:10080/rep/login 访问服务器 ，配置文件`.evn.production.local` 里设置 `VUE_APP_DOMAIN='docker1.emicloud.com'`
6. nginx的log文件在我本机目录`/usr/local/Cellar/nginx/1.15.8/logs/ql.access.log`



### nginx limit_req
